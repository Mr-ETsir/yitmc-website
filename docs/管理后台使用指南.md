# YITMC 官网内容管理后台（/admin）使用指南

> 目标：**每一任社长不进服务器、不注册任何账号、不懂代码**，
> 手机或电脑浏览器打开后台，输入密码，全中文表单编辑，保存即全网生效。

## 一、它是什么

- 后台地址：https://www.yitmc.cn/admin/ （以实际域名为准）
- 登录方式：**一个管理密码**（无 GitHub、无邮箱注册）
- 编辑内容：作品展示 / 社团动态 / 成员风采 / QQ群与微信联系方式及二维码图片 / 首页数据亮点
- 生效方式：点「保存」直接写入服务器上的数据文件，**无需部署，刷新网站即可看到**
- 图片上传：支持 jpg / png / webp / gif，单张 ≤ 8MB

可编辑的数据保存在网站根目录的 data/*.json 与 uploads/ 图片目录中；
打包内置的 src/data/*.json 仅作为兜底初始值。

## 二、一次性开通步骤（维护者操作）

1. 配置管理密码：参照 `docs/admin-config.sample.php`，在本地创建 `admin-config.php`
   （与 `admin-api.php` 同目录，即 `img/` 下），写入真实密码后再构建上传。
   该文件已被 `.gitignore` 排除，**绝不提交到代码仓库**；
   构建时会随 `dist/` 一起进入 `dist/admin-config.php`。
   （或先上传后登录，在后台「设置 → 修改管理密码」里修改，改完即可删除该文件。）
2. 将整个 dist 目录上传到服务器网站根目录（包含 admin-api.php、data/、uploads/ 占位等）。
3. 确认服务器满足：PHP 7.4+；若宝塔面板，通常默认即满足。
4. 浏览器打开 /admin/ → 输入密码登录 → 随便改一处文字 → 保存 → 刷新官网验证生效。
5. 若提示「data/ 目录不可写」：在宝塔中把网站目录所有者改为 www（或给 data/、uploads/
   目录写入权限）后重试。

## 三、社长日常操作（手机或电脑均可）

| 想做什么 | 怎么做 |
| --- | --- |
| 发布一条社团动态 | 社团动态 → 「+ 发布一条新动态」→ 填标题/日期/类型/摘要/正文 → 保存 |
| 展示一件新作品 | 作品展示 → 「+ 添加一件作品」→ 上传封面图、选分类、填简介与作者 → 保存 |
| 更换 QQ 群二维码 | 联系方式 → QQ 群二维码 → 「上传新图片」→ 保存 |
| 更换社长微信号 / QQ 群号 | 联系方式 → 改对应文字框 → 保存 |
| 新增成员风采 | 成员风采 → 「+ 添加一位成员」→ 姓名/职务/头像/介绍/年级 → 保存 |

保存成功后页面会有绿色提示；旧内容随时可以改回来。编号 ID 保持比上一条 +1 即可（系统会自动填好）。

## 四、换届交接（约 1 分钟）

1. 现任（或离任前）社长登录后台 → 「设置」→ 修改管理密码；
2. 把新密码当面或私下告诉下一任社长；
3. 完成。之后任何人拿不到密码都无法编辑，服务器始终不需要再碰。

## 五、常见问题

1. **打开 /admin 显示空白或跳回首页**
   说明服务器不支持 PHP 或未上传 admin-api.php。
   若确认没有 PHP 环境，联系开发者切换到云端存储版本（界面完全相同）。

2. **保存时提示「目录不可写」**
   宝塔面板 → 网站 → 该站点 → 把运行目录权限调整为 www 用户可写；重点检查 data/ 与 uploads/。

3. **忘记管理密码**
   由维护者通过 FTP 删除服务器上的 auth 文件（yitmc-admin/auth.json，位于网站目录上一级），
   再确认服务器上存在 admin-config.php（没有就按样例重建），
   密码即恢复为 admin-config.php 里配置的密码。

4. **改错了想回退**
   联系维护者从 Git 历史 / 本地备份恢复对应的 data/*.json 即可。

5. **图片传错了**
   无妨：重新上传正确图片并再次保存即可覆盖引用；旧图片文件留存于 uploads/ 不影响展示。
